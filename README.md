# Roam_Nepal
The project “Roam Nepal” is a tourism-based website designed to showcase popular travel destinations across Nepal. The website provides users with information about various locations, helping them explore and plan their travel experience. It focuses on clean design, easy navigation, and responsive layout using HTML and CSS.
